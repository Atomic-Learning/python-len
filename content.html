The length of a string is the number of characters it contains. You find the length using the len() function:

Basic Usage

print(len("hello")) print(len("Python")) print(len("")) print(len("Hello world"))

With Variables

You can call the len function and pass a string as an argument:

word = "example" length = len(word) print(length) print(type(length))

Important: Spaces and Special Characters Count

Don't forget that spaces and special characters are counted:

phrase = "A B C!" # 3 letters, 2 spaces, 1 punctuation = 6 characters total print(len(phrase))
