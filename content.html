The len() function is a built-in function in Python that returns the number of items in a collection. It can be used with various types of collections, including collections like strings, lists, dictionaries and sets. Here, we'll use strings and lists as an example.

Usage

To find the number of items in a collection, you can simply pass the collection as an argument to the len() function. For example: string1 = "Hello, World!" print(len(string1)) list1 = [0, 1, 2, 3, 4] print(len(list1)) The returned value will be an integer representing the number of characters in the string or the number of items in the list.

Special Characters in Strings

Special characters in strings, such as spaces, punctuation, and escape characters, are also counted as individual characters when using the len() function. For example: string1 = "Hello, World!" print(len(string1))
